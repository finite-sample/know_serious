# Correctness-coding audit plan

This retrospective audit follows reproduction and the knowledge-score sensitivity
analysis. The published numerical results, answer keys, proposed windows, and
candidate classification-change counts have already been examined. The new model
comparisons below were specified before fitting alternative economic outcomes.

The audit distinguishes factual answers, the numeric/category codes representing
them, payment eligibility, the analysis definition of correctness, and the later
mapping of errors to partisan congeniality. Matching original code alone does not
validate any of these definitions.

For every economic item, export the factual key, units, inclusive boundaries under
all five released window definitions, the intended rationale, observed correct
shares, and numbers changing category. Keep categorical keys unchanged. Compare
pooled monetary-versus-control and Study 2 treatment contrasts in correct answers
and congenial-minus-uncongenial bias, with respondent-cluster delta intervals.

Fit the published Table 4 model with its original knowledge score and exactly its
1,260 respondents / 6,233 responses under: published 33%, published 23%, relative
10%, payment windows, a coherent one-percentage-point / ten-cent window, and the
historical worksheet's symmetric 23% uninsured window. The last two are explicitly
alternative definitions, not silent repairs of the publication baseline. Use
31/61-node integration checks, the original variance penalty, and direct equal-item
contrasts between knowledge scores 4.5 and 9.5 with inverse-Hessian delta intervals.
Intervals are pointwise and conditional on fixed window choices; neither selection
of those windows nor the exploratory family is incorporated into inference.

Also compare the main 33% coding using available date-linked reference values:
5.1% unemployment only for interviews beginning on or after April 5, 2008 (the day
after the April 4 release), otherwise 4.8%; and the existing respondent-linked
national gas-price series. Recenter the main windows without changing their widths.
The gas linkage follows interview finish date and its label says previous-day
price; item-specific timestamps and the original AAA download are unavailable.
These are sensitivity targets for contemporaneous accuracy, not recovered payment
rules. The committed derived reference file contains keys and respondent IDs only,
not interview timestamps, state prices, or geography.

Audit monetary units, invalid percentages, refusal versus missing treatment, and
the special estate-tax partisan direction separately. Do not assign a partisan
direction to unanswered questions. Compare accuracy with recorded refusals counted
as incorrect as a separate denominator sensitivity. For general knowledge, trace
all categorical keys through labels, randomized option order, checkpoint scores,
questionnaire text, and official historical sources. A typo in a programming note
is not a scoring error when the actual key is correct.

Report code defects separately from construct choices, dated-key ambiguities, and
historical worksheet discrepancies. Preserve the published outputs and identify
which reported tables actually use a questionable variable before claiming impact.
