# Knowledge and item-selection follow-up

The first sensitivity family has now been estimated; see the generated
[knowledge audit](knowledge_audit.md) and the [retrospective plan](sensitivity_plan.md).
The published-specification estimates remain the baseline.

Completed checks compare strict Senate credit with both answer keys, omit the
Senate item, add six excluded knowledge questions, verify the sample impact of
missing knowledge, and omit each published economic item in turn. These checks
separate score changes from sample changes and include probability-scale intervals.

Remaining extensions are the original missing 2008 delivery and visual recoder,
randomized knowledge-question formats, leave-one-knowledge-item-out comparisons,
and the rationale for excluding the extra knowledge questions. Adding the 2004
international-tax and campaign-proposal questions requires explicit construct and
partisan-direction definitions. Those additions have not been silently folded into
the published economic-outcome scale.
